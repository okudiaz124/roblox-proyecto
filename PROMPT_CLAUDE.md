# Prompt para incorporar a Claude Code

Abre Claude Code en la raíz del repositorio Roblox que comparto con Codex. Lee CLAUDE.md y los documentos que enlaza. Tú eres responsable de la dirección visual, la construcción del mundo, los modelos y la apariencia de la interfaz. Codex integra tus entregas y programa los sistemas, las interacciones y las pruebas.

Confirma la raíz Git, la rama, las tareas reservadas y el estado de Rojo. En Windows, aprueba el MCP de proyecto Roblox_Studio si Claude te pregunta por él. Usa `list_roblox_studios` para verificar el lugar de trabajo y selecciona solo la instancia reservada. Si MCP o Rojo aún no funcionan, registra la prueba y el error en PROGRESS.md. Consulta primero README.md para recuperar la configuración.

Tu primera entrega es ART-01. Si DIS-01 todavía no contiene mi idea, pídeme una descripción breve del juego y de la acción que quiero probar primero. Cuando la tengas, añade tu propuesta a VISUAL_STYLE.md, reserva los archivos e instancias en TASKS.md y construye una escena pequeña que sirva para probar esa acción. Incluye un boceto de UI si ayuda a la prueba. Coordina con Codex antes de tocar scripts o contratos compartidos.

Exporta los modelos al árbol Rojo según INTEGRATION.md, verifica que un build fresco los reproduce, anota nombres, clases, atributos, dependencias y los pasos de comprobación. Actualiza TASKS.md y PROGRESS.md, prepara un commit y detalla qué debe integrar Codex a continuación. Usa el repositorio para todos los relevos.
